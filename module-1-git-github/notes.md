## What is Git? What is GitHub? (explain like you're teaching a friend who's never used either)

Git is a tool, use to manipulate versions of your projects. it allows you to save chnages, bring back old version of your projects, and control file location based on repository or branches. 
Github is where you store all your projects. it acts as a bag with separators for each of your projects to make them organized and you won't misplaced it here if you plan to store them here. this is the platform that will help you manage all your projects and it allows multiple users to access files without affecting the main file using the branches not unless you requested a pull and merge of  what you modified.

## Key vocabulary (in your own words)

repository: this is the container of your projects to make each project organized.
commit: is the method to save your changes. it also acts as a checkpoint.
branch: branch is a separators inside your repository. it acts as a section of your main repository and allows you to modify the project without affecting the main project.
push/pull: push is when you want to apply the changes you did on a project. pull is te method to get the latest and update project on a branch.
pull request: this happens after you push your changes. this section allows the admin to look for the request and to validate the changes that are made.
merge conflict: this happens when an error occurs on your pull request.
